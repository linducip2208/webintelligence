# ما هي Web Intelligence؟

> منصة الاستخبارات والتحقيق: من البحث إلى المراقبة في مساحة عمل واحدة.

## خط الأنابيب

```text
بيانات ← معلومات ← معرفة ← أدلة ← استخبارات ← دعم القرار
```

1. **البحث / التحقيق** — ابدأ من أي شيء: نطاق أو رابط أو IP أو بريد أو منظمة أو هوية أو كلمة مفتاحية.
2. **الجمع** — المهام تجلب مصادر الويب وAPI والمستندات عبر سلم الاستراتيجيات.
3. **التطبيع** — اللقطات الخام تصبح سجلات نظيفة قابلة للمقارنة مع درجات جودة.
4. **حل الكيانات** — الإشارات المتعددة تندمج في هويات واثقة.
5. **الرسم البياني للعلاقات** — حواف الملكية والاستضافة والإحالة القابلة للاجتياز.
6. **الربط** — البنية المشتركة تصبح نتائج مرشحة.
7. **المخاطر** — درجات 0–100 قابلة للتفسير مع العوامل والأدلة.
8. **النتائج** — فرز بالخطورة والثقة والنسب.
9. **الأدلة** — مصادر محفوظة بالنسب والسلامة.
10. **القضية** — حاوية العمل: ملاحظات ومهام وأعضاء وروابط.
11. **التقرير** — ست صيغ تصدير لأصحاب المصلحة.
12. **المراقبة** — قوائم مراقبة وتنبيهات وسير عمل تبقى يقظة.

## المبادئ

- **بيانات حقيقية فقط.** اللوحة لا تعرض أرقامًا تجريبية أبدًا. الشاشة الفارغة تعني أن الجمع لم يعمل بعد — وتخبرك كيف تبدأ.
- **الأدلة قبل الاستنتاجات.** مخرجات الذكاء الاصطناعي موسومة؛ واستنتاجات المحلل تستشهد بالأدلة.
- **صدق غير المتزامن.** لا شيء يدّعي الاكتمال وهو في الانتظار.
- **جمع محترم.** يُحترم robots.txt والشروط؛ لا تجاوز لتسجيل الدخول أو CAPTCHA.
