# توثيق Web Intelligence

> منصة الاستخبارات والتحقيق. ابحث وحقّق واربط وقيّم المخاطر واحفظ الأدلة وابنِ القضايا وأصدر التقارير وراقب.

## ابدأ من هنا

- **[أول تحقيق لك](/docs/ar/getting-started/first-investigation)** — جولة كاملة من 20 خطوة بلقطات شاشة حقيقية.
- **[خمس دقائق إلى أول نتيجة](/docs/ar/getting-started/5-minute-investigation)** — جولة سريعة من عشر خطوات.
- **[ما هي Web Intelligence؟](/docs/ar/getting-started/overview)** — المفاهيم بلغة بسيطة.
- **[نظرة على API](/docs/ar/api/overview)** — للمطورين.

## سير التحقيق

```text
بحث ← هدف ← نطاق ← جمع ← تطبيع ← حل الكيانات ← رسم بياني
  ← ربط ← مخاطر ← نتائج ← أدلة ← قضية ← تقرير ← مراقبة
```

اقرأ كل مرحلة في [دورة حياة التحقيق](/docs/ar/investigations/investigation-lifecycle).

## القدرات الأساسية

- **جمع شفاف** — كل مهمة تُظهر في الانتظار أو قيد التشغيل أو مكتملة أو فاشلة أو ملغاة. انظر [الجمع](/docs/ar/investigations/collection).
- **رسم بياني موثق** — عقد وحواف واجتياز وأقصر مسار مدعومة بالأدلة. انظر [الرسم البياني](/docs/ar/intelligence/graph).
- **الأدلة قبل الاستنتاجات** — مخرجات الذكاء الاصطناعي موسومة دائمًا. انظر [الادعاءات والتحقق](/docs/ar/evidence/claims).
- **مراقبة تُغلق الحلقة** — قوائم مراقبة وتنبيهات وسير عمل. انظر [قوائم المراقبة](/docs/ar/monitoring/watchlists).
