# Roles & Permissions

> Built-in and custom roles: exactly what each permission unlocks.

| Role | Powers |
|---|---|---|
| owner | Everything, including billing and member removal (last owner is protected) |
| admin | Configure, manage members, retention, providers |
| analyst | Investigate, triage, build cases and reports |
| viewer | Read dashboards, findings, evidence and reports |

Custom roles compose the same permissions. Every denial returns 403 with an audit record.
