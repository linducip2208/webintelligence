1. Pengenalan

Universal Intelligence Platform (WebIntel) adalah aplikasi monitoring & intelijen data web: mengambil data publik dari website/API/dokumen, lalu mengubahnya menjadi informasi siap pakai — pantauan harga, pergerakan kompetitor, berita, perubahan situs, knowledge graph, sampai laporan eksekutif.

Alur kerja: DATA → INFORMATION → KNOWLEDGE → EVIDENCE → INTELLIGENCE → DECISION SUPPORT. Prinsip penting: dashboard hanya menampilkan data nyata — tidak ada angka dummy. Kalau masih kosong, berarti belum ada aktivitas koleksi.

3. Instalasi & Menjalankan

1Siapkan database MySQL (contoh Laragon, user root tanpa password): 
mysql -u root -e "CREATE DATABASE IF NOT EXISTS webintel CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci; CREATE USER IF NOT EXISTS 'webintel'@'%' IDENTIFIED BY 'GANTI_PASSWORD'; GRANT ALL PRIVILEGES ON webintel.* TO 'webintel'@'%'; FLUSH PRIVILEGES;"
2Install dependensi Python: 
cd source\python
pip install -r requirements.txt
pip install "bcrypt==4.0.1"
3Set koneksi database (PowerShell, sekali saja — tersimpan permanen): 
setx DATABASE_URL "mysql+pymysql://webintel:GANTI_PASSWORD@127.0.0.1:3306/webintel"
Tutup-buka terminal agar variabel berlaku.
4Jalankan server: 
cd source\python
python -m uvicorn app.main:app --port 8000
5Buka aplikasi: Dashboard http://127.0.0.1:8000/ · Panduan ini /docs · Swagger /api-docs. Cek kesehatan: GET /readyz — pastikan database: backend=mysql.
6Kolektor Go (opsional): 
cd source\go\collector
go test ./...
go build -o ..\..\..\build\linux\collector .\cmd\collector

5. Mulai Cepat 5 Menit

1Buka Dashboard, isi API token / key bila REQUIRE_AUTH=1 (default mati di dev).
2Menu Sources → sources: buat Project (isi nama → Add).
3Menu targets: isi project_id, domain, url → Add. Klik Test untuk cek koneksi & rekomendasi strategi.
4Menu jobs: isi project_id, target_id, url → Add, lalu Run now. Status success = data masuk.
5Kembali ke Dashboard → Refresh: kartu Jobs, Feed, dan menu lain (prices, changes, articles) kini ada isinya.

6. Panduan Fitur

6.1 Dashboard

Ringkasan real-time: total job (sukses/gagal), alert terbuka, titik harga, estimasi biaya, peluang, kualitas data, panggilan AI, status sistem. Klik Refresh. Ganti bahasa via dropdown sidebar (English/Indonesia), mode gelap/terang via tombol ◐.

6.2 Sources (sources, targets, connectors, jobs, reliability)

Kelola proyek, target pantauan, konektor RSS/REST/CSV (uji dengan test, jalankan dengan execute), dan job koleksi. reliability menampilkan skor keandalan target setelah ada riwayat koleksi nyata.

6.3 Job & Jadwal (jobs, schedules)

Job dijalankan manual (Run now) atau otomatis via schedules (interval/cron). Tombol Run scheduler now memicu jadwal yang jatuh tempo. Job gagal bisa retry/cancel; yang gagal permanen terlihat di dlq.

6.4 Harga & Intel Pasar (products/prices, changes, articles, analytics, opps)

products/prices: riwayat & volatilitas harga. changes: perubahan situs (NEW/CHANGED/REMOVED). articles: kelola artikel berita. analytics: tren & anomali. opps: peluang terdeteksi (z-score).

6.5 Knowledge & Riset (graph, events, evidence, claims, documents, research, runs, reports, findings)

graph: tambah node/edge, telusuri & render SVG. claims: verifikasi klaim terhadap bukti. documents: ingest teks/HTML/CSV. research: tulis pertanyaan → Plan → run → analisis. reports: buat laporan lalu View/ekspor (web/PDF/CSV/JSON/XLSX/markdown).

6.6 Monitoring (watchlists, alerts, workflows, webhooks)

watchlists: daftarkan keyword/perusahaan/domain → Evaluate untuk cek kecocokan. alerts: aturan peringatan + Send (in-app/email/webhook). workflows: otomasi pemicu → aksi (Run manual untuk tes). webhooks: daftarkan URL penerima + Test.

6.7 Dataset (datasets)

Kumpulkan data menjadi dataset berversi: lihat versions, bandingkan diff, kembalikan via rollback, impor CSV, publish/archive saat selesai.

6.8 AI & Pencarian (ai, search)

ai: status provider & chat berbasis bukti (jawaban menyertakan sitasi). search: pencarian global + semantik. Butuh kredensial provider (mis. Muse Spark) agar chat live; tanpa itu endpoint health tetap jalan.

6.9 Admin & Billing (organizations, users, apikeys, audit, health, costs, billing)

Kelola organisasi, user, API key berskop & kedaluwarsa, lihat audit log, kesehatan sistem, ringkasan biaya & budget, serta paket/kuota billing.

8. Autentikasi & Keamanan

Default dev: terbuka (tanpa login). Untuk produksi set REQUIRE_AUTH=1: semua /api/v1/* butuh Bearer token (dari POST /api/v1/auth/login) atau X-API-Key (dibuat di menu apikeys, berskop & bisa kedaluwarsa & di-revoke). Proteksi lain: anti-SSRF + allowlist egress, isolasi data per organisasi, rate-limit per identitas (429 + Retry-After), batas ukuran body (413), log menyensor rahasia.

curl -X POST http://127.0.0.1:8000/api/v1/auth/login -H "Content-Type: application/json" -d "{\"email\":\"admin@local\",\"password\":\"...\"}"
curl http://127.0.0.1:8000/api/v1/projects -H "Authorization: Bearer TOKEN"
curl http://127.0.0.1:8000/api/v1/projects -H "X-API-Key: wi_xxxx"

11. Troubleshooting

GejalaPenyebab umum → Solusi
Data (project/job) hilang setiap restart, padahal MySQLSeed lama gagal FK 1452 dalam satu transaksi → organizations kosong → tulis ber-FK hanya di memori (sudah diperbaiki: repo._seed commit bertahap). Cek: organizations harus ada 1 baris; kalau kosong, restart server (seed otomatis)
/readyz: backend=sqlite padahal mau MySQLEnv DATABASE_URL tidak sampai ke proses server, atau pymysql belum di-install → app fallback diam-diam. Solusi: pip install -r requirements.txt, lalu setx DATABASE_URL "mysql+pymysql://user:pass@127.0.0.1:3306/webintel", tutup-buka terminal, restart server

12. FAQ

Apakah ini toko online? Bukan. Ini tool monitoring/riset data web.

Apakah data contoh bawaan ada? Tidak — semua angka berasal dari aktivitas nyata. Jalankan koleksi dulu (§5).

Bahasa apa saja? UI dashboard: Inggris & Indonesia. Dokumentasi README: Inggris, Indonesia, Arab.

Butuh Docker? Tidak. Python + MySQL (+ Nginx/systemd di produksi) cukup.

Apakah scraping melanggar aturan situs? App menghormati robots.txt/ToS, tidak menembus login/CAPTCHA. Pantau hanya data publik & patuhi ketentuan tiap situs.
